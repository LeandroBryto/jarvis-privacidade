Política de Privacidade do Jarvis Secretária

Última atualização: 26 de outubro de 2026.

O que é o aplicativo

O Jarvis é um aplicativo pessoal que roda no computador do próprio usuário. O desenvolvedor não opera servidores que recebam os dados dos usuários.

Dados do Google que o aplicativo acessa

Somente com a autorização do usuário, o aplicativo usa estes acessos somente de leitura: mensagens do Gmail (gmail.readonly) e compromissos do Google Agenda (calendar.readonly).

Como os dados são usados

  • Os dados são lidos no computador do usuário e usados apenas para falar um resumo (quantidade de e-mails não lidos, remetentes, assuntos e compromissos do dia).
  • Não são vendidos, não são compartilhados com terceiros, não são usados para publicidade e não são transferidos para servidores do desenvolvedor.
  • Por padrão, nenhum conteúdo de e-mail é enviado a serviços de inteligência artificial. Se o usuário ligar, por conta própria, a opção "deixar a IA ler meus e-mails", trechos podem ser enviados ao provedor de IA que ele mesmo configurou (por exemplo, Google Gemini ou Anthropic Claude), para gerar o resumo.
  • O aplicativo não grava o conteúdo dos e-mails de forma permanente.

Armazenamento e segurança

As credenciais de acesso (tokens) ficam no Gerenciador de Credenciais do Windows do próprio usuário. O serviço do aplicativo só aceita conexões do próprio computador (127.0.0.1).

Conformidade

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O usuário pode retirar a permissão a qualquer momento em myaccount.google.com/permissions ou desconectando o Google na tela de Conectores do aplicativo.
